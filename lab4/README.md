Этот набор данных относится к распознаванию цветов. Набор данных содержит необработанные изображения в формате JPEG пяти видов цветов:

# 2. Предобработка данных
Я решила реализовать сверточную нейросеть (CNN) для своей работы.

Для обучения нейросети необходимо было преобразовать исходные файлы фотографий в математический формат (тензоры), с которым может работать библиотека TensorFlow и Keras. Внутри директории, где лежит мой датасет, находится 5 подпапок, названия которых соответствуют названиям классов цветов: daisy (ромашки), dandelion (одуванчики), roses (розы), sunflowers (подсолнухи) и tulips (тюльпаны). В каждой подпапке хранились .jpg фотографии соответствующего цветка.

Декодирование и стандартизация размера. Поскольку сверточная нейронная сеть (CNN) имеет фиксированный размер входного слоя (Input Layer), все фотографии разного размера необходимо было привести к единому стандарту. Этот шаг выполнялся автоматически на этапе загрузки данных функцией image_dataset_from_directory через параметр image_size=(180, 180). Программа считывает байты JPEG-файла с диска и декодирует их в RGB-матрицу. Выполняется интерполяция изображения (процесс, при котором значения пикселей в изображении определяются на основе значений окружающих пикселей) до квадрата размером 180x180 пикселей.

Итоговый тензор каждого изображения принимает форму (180, 180, 3). Выбор именно такого размера является компромиссом между скоростью обучения (слишком большие картинки перегрузят видеокарту) и точностью (на слишком маленьких картинках сольются важные черты лепестков).

Функция tf.keras.utils.image_dataset_from_directory сама сканирует названия папок и присваивает картинкам внутри них соответствующие числовые метки (0, 1, 2, 3, 4). Мне не пришлось вручную писать код для сопоставления картинок с их классами.

После декодирования изображения цвет каждого пикселя представлен целым числом в диапазоне от 0 (черный) до 255.

Однако нейронные сети работают с использованием градиентных методов оптимизации (алгоритм Adam, обратное распространение ошибки), которые крайне чувствительны к масштабу входных данных. Большие числа (например, 200 или 250) приводят к нестабильности градиентов, из-за чего сеть может вообще не обучиться или обучаться недопустимо долго.!!!!!!!!!!!!

Исходя из выбранной архитектуры сети применялся соответствующий математический метод нормализации. Использовался слой tf.keras.layers.Rescaling(1./255). Этот слой просто делит значение каждого пикселя на 255. В результате все значения пикселей переводятся из диапазона [0; 255] в диапазон вещественных чисел [0.0; 1.0]. Такая нормализация делает распределение входных данных удобным для работы функций активации (в частности, ReLU, используемой в моих сверточных слоях).

Батчинг. В качестве последнего этапа предобработки изображения объединялись в пакеты (батчи) по 32 штуки с помощью параметра batch_size=32, так как обучать сеть по одной картинке неэффективно, а загрузить сразу все 3000 картинок в видеокарту невозможно из-за нехватки памяти.

Таким образом, итоговый тензор, который физически подается на вход первого слоя нейронной сети, имеет размерность (32, 180, 180, 3) — пакет из 32 цветных изображений размером 180x180.

# 3. Разделение датасета

Я сделала загрузку фотографий из папки на компьютере и разбила их на три независимые выборки:
- Обучающая выборка (Training set — 80% данных). Эта часть была сгенерирована путем передачи аргументов validation_split=0.2 и subset="training". На этих изображениях нейросеть корректирует свои математические веса (учится).
- Валидационная выборка (Validation set — 10% данных). Валидационная выборка используется в процессе обучения (после каждой эпохи). Сеть не учится на этих картинках, но пытается их угадать. Это позволяет нам строить графики val_loss и val_accuracy, чтобы контролировать момент наступления переобучения (overfitting).
- Тестовая выборка (Test set — 10% данных). Это отложенная часть данных, которая используется исключительно один раз — в самом конце проекта. Она нужна для непредвзятой оценки качества готовой модели, чтобы подтвердить, что модель умеет распознавать цветы в реальных условиях. Разделение было выполнено с помощью методов .take() и .skip() библиотеки tf.data.

Так же была сделана оптимизация производительности. Чтение тысяч картинок с жесткого диска — очень долгий процесс, который может заставить видеокарту "простаивать" в ожидании данных. Чтобы этого избежать, был применен конвейер оптимизации tf.data.AUTOTUNE:
- .cache(). При первой эпохе обучения программа считывает картинки с диска и сохраняет их в оперативную память (ОЗУ). Все последующие эпохи берут данные из быстрой ОЗУ, что сокращает время обучения в несколько раз.
- .shuffle(1000). Тщательно перемешивает картинки перед каждой эпохой, чтобы нейросеть не заучивала последовательность (например, чтобы она не привыкла, что после пяти ромашек всегда идут три розы).
- .prefetch(buffer_size=AUTOTUNE). Создает асинхронный конвейер. Пока процессор загружает и подготавливает пакет картинок №2, видеокарта уже обучает нейросеть на пакете №1. Это обеспечивает максимальную загрузку вычислительных мощностей.

# 4. Аугментация
Аугментация — это процесс искусственного расширения набора обучающих данных за счет применения случайных геометрических и цветовых преобразований к исходным изображениям прямо в процессе обучения.

Если обучающая выборка недостаточно велика (в нашем случае это несколько тысяч изображений цветов), модель быстро запоминает каждую фотографию наизусть. Это явление называется переобучением (overfitting): нейросеть показывает 100% точность на тренировочных данных, но начинает сильно ошибаться на новых, ранее не виданных картинках, так как она запомнила конкретные пиксели, а не общие признаки объектов (форму лепестков, структуру стебля). Чтобы предотвратить переобучение и повысить обобщающую способность модели, в работе был применен метод Аугментации данных (Data Augmentation). 

Вместо того чтобы один раз загрузить фотографию ромашки и показывать её нейросети на каждой эпохе в неизменном виде, мы при каждом показе слегка искажаем эту фотографию. Таким образом для нейросети каждый раз генерируется уникальное изображение, имитирующее изменения в реальном мире (разный ракурс съемки, приближение, наклон камеры).

Я реализовала аугментацию как отдельный интегрированный блок (слой tf.keras.Sequential), который был встроен в самое начало нейронной сети перед сверточными слоями. Я применила следующие трансформации:
- RandomFlip("horizontal")(Случайное отзеркаливание): С вероятностью 50% изображение цветка отражается по горизонтали. Для цветка левая и правая стороны семантически равнозначны (в отличие от, например, текста), поэтому данная операция удваивает эффективный объем датасета, обучая модель инвариантности к ориентации объекта.
- RandomRotation(0.1)(Случайное вращение): Поворачивает изображение на случайный угол в диапазоне ±10% от полного круга (примерно ±36 градусов). Это имитирует ситуацию, когда пользователь фотографирует цветок, держа телефон под небольшим наклоном.
- RandomZoom(0.1)(Случайное масштабирование): Случайным образом приближает или отдаляет изображение на величину до 10%. Это помогает нейросети научиться распознавать как крупные бутоны, снятые в режиме макро, так и цветы, находящиеся на небольшом отдалении от объектива.

# 5. Построение архитектуры нейронной сети (CNN)
Для распознавания изображений наиболее подходящей архитектурой являются именно сверточные нейронные сети, так как они специально разработаны для анализа двумерных данных, то есть изображений. В отличие от обычных полносвязных сетей, CNN умеют учитывать пространственную структуру картинки: расположение контуров, форм, текстур и цветовых переходов. 

Архитектура строилась по принципу:
- На вход подается изображение фиксированного размера.
- Сверточные слои извлекают признаки.
- Слои подвыборки уменьшают размер карт признаков и оставляют самое важное.
- Слои регуляризации препятствуют переобучению.
- Полносвязные слои выполняют итоговую классификацию.
- Последний слой выдает вероятность принадлежности изображения к одному из 5 классов.

1. data_augmentation. Это специальный блок аугментации данных, встроенный прямо в архитектуру модели. Он применяется только во время обучения и случайным образом изменяет изображения: отражает, поворачивает и масштабирует их. Назначение этого блока — увеличить разнообразие обучающих примеров и сделать модель устойчивой к различным вариантам съемки. Благодаря этому сеть учится распознавать не конкретную фотографию, а сам класс объекта.
2. Rescaling(1./255). Этот слой выполняет нормализацию входных данных. Значения пикселей в обычных изображениях находятся в диапазоне от 0 до 255. Слой делит каждый пиксель на 255, переводя значения в диапазон от 0 до 1.
3. Conv2D(32, 3, padding='same', activation='relu'). Это первый сверточный слой. Он содержит 32 фильтра размером 3x3. Каждый фильтр сканирует изображение и ищет определенные локальные признаки. На первых слоях сеть обычно находит: контуры, границы объектов, линии, простые текстуры, цветовые переходы. Параметр padding='same' означает, что размеры изображения по ширине и высоте сохраняются после свертки. Функция активации ReLU зануляет отрицательные значения и оставляет положительные. Это делает модель нелинейной и позволяет ей изучать сложные зависимости.
4. MaxPooling2D(). После первого сверточного слоя применяется слой подвыборки. Его задача — уменьшить пространственный размер карты признаков. Этот слой "сжимает" изображение признаков и оставляет только самые сильные ответы нейронов. Это дает сразу несколько преимуществ: уменьшает объем вычислений, снижает вероятность переобучения, делает модель более устойчивой к небольшим смещениям объекта на изображении.
5. Conv2D(64, 3, ...). Второй сверточный слой работает уже не с исходной картинкой, а с картами признаков, полученными после первого блока. Здесь число фильтров увеличивается до 64, так как на более глубоком уровне сеть должна искать более сложные структуры. На этом этапе модель начинает замечать: группы лепестков, форму цветка в целом, внутреннюю текстуру бутона, характерную организацию центральной части цветка.
6. Второй MaxPooling2D(). Снова выполняется уменьшение размерности. После этого сеть теряет часть мелких деталей, но сохраняет наиболее важную информацию о форме и структуре.
7. Conv2D(128, 3, ...). Третий сверточный слой содержит уже 128 фильтров. На этой глубине модель извлекает высокоуровневые признаки. Теперь она анализирует не просто отдельные границы и текстуры, а целые комбинации признаков, характерные для конкретных классов цветов. Например: вытянутые лепестки тюльпанов, крупную темную серединку подсолнуха, плотную структуру розы, тонкие белые лепестки ромашки, особенности формы одуванчика.
8. Третий MaxPooling2D(). После третьего сверточного блока снова происходит уменьшение размерности. Это завершает этап извлечения признаков.
9. Dropout(0.4). Данный слой выполняет регуляризацию. Во время обучения он случайным образом отключает 40% нейронов предыдущего слоя. Смысл этого механизма заключается в следующем: модель не может "привязаться" к отдельным нейронам и вынуждена учиться распределять знания по всей сети. Это снижает переобучение и делает итоговую модель более устойчивой.
10. Flatten(). После серии сверточных и пулинговых слоев данные имеют форму многомерного тензора. Однако полносвязные слои работают только с одномерными векторами. Слой Flatten() разворачивает многомерную карту признаков в один длинный вектор. Это переход от этапа "извлечения признаков" к этапу "принятия решения".
11. Dense(128, activation='relu'). Это первый полносвязный слой классификатора. Он получает все признаки, извлеченные предыдущими слоями, и учится комбинировать их для определения конкретного класса. Именно здесь сеть начинает принимать решение вида: если есть такие-то признаки формы, такие-то текстуры, такой-то цветовой паттерн, то изображение, вероятно, относится к определенному цветку.
12. Dropout(0.5). Этот слой отключает уже 50% нейронов. Он нужен для усиленной защиты от переобучения, особенно перед финальной классификацией.
13. Dense(num_classes, activation='softmax'). Это выходной слой модели. Число нейронов равно числу классов, то есть 5. Каждый нейрон соответствует одному классу: daisy, dandelion, roses, sunflowers, tulips. Функция softmax преобразует выходные значения в вероятности. В результате модель возвращает вектор из 5 чисел, сумма которых равна 1.

Например: [0.02, 0.05, 0.10, 0.80, 0.03]. Это означает, что модель считает изображение подсолнухом с вероятностью 80%.
